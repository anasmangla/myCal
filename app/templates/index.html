How To Use myCal

A quick guide for planning, styling, sharing, and editing notes inside the calendar.

Quick Start

Use this monthly view to plan events, show built-in faith and holiday dates, and export a clean printable calendar.

  • Choose the month from the selector at the top of the page.
  • Use the top toggles to decide whether USA Jamaat, Islamic dates, and U.S. holidays are visible.
  • Double-click an in-month day cell to create a new event.
  • Click or double-click one of your own event chips to edit it.
  • Open Settings to adjust colors, fonts, sizes, and audience colors.
  • Use Print / Save PDF, Export image, Export ICS, or Export JSON when you are ready to share or back up the month.
Top Bar And Toggles
  • The month selector changes the active month and updates the browser tab title.
  • Settings controls colors, grid lines, typography, and audience chip colors.
  • USA Jamaat shows or hides the built-in 2026 USA Jamaat feed for the selected month. It is on by default.
  • Islamic dates controls the Islamic date labels shown inside day cells.
  • U.S. holidays shows or hides federal holidays.
  • Help opens this guide at any time.
USA Jamaat Calendar
  • The USA Jamaat events come from the built-in 2026 national Jamaat calendar data saved with the app.
  • Only the events that fall within the currently selected month are shown.
  • These Jamaat items are read-only feed entries, not normal user-created events.
  • Right-click a USA Jamaat event chip and choose remove to hide that occurrence on that day.
  • Hidden Jamaat occurrences are remembered locally for that month in your current browser.
  • Turn the USA Jamaat toggle off if you want to hide the full Jamaat feed for the selected month.
Working With Events
  • Double-click a regular in-month date cell to add an event quickly.
  • Leave Start time blank if the event should be treated as all-day.
  • Use the weekday checkboxes in the event form to repeat an event weekly.
  • Click or double-click one of your own event chips to edit it.
  • Drag one of your own event chips to another in-month day cell to move it.
  • Use short titles and optional notes/location so chips stay readable in the calendar grid.
Right-Click Actions
  • Right-click a date cell to change its background color or hide holiday / Islamic labels for that day.
  • Right-click one of your own event chips to modify, move, or remove that event.
  • Right-click a USA Jamaat event chip to hide only that day's occurrence.
  • The remove action on a Jamaat chip hides that occurrence instead of editing the underlying feed.
Export And Sharing
  • Print / Save PDF creates a printable month snapshot.
  • Export image saves the visible calendar as an image.
  • Export ICS downloads the events visible in the current month, including USA Jamaat events when that toggle is on.
  • An ICS file is a snapshot export. If you change the calendar later, recipients will need a new file to get the updated month.
  • Export JSON and Import JSON let you back up or restore the calendar data.
Saved Data
  • The Flask app saves events and date styles to its database.
  • Hidden holiday labels, hidden Islamic labels, and hidden USA Jamaat occurrences are remembered locally in this browser for the current month.
  • Importing JSON replaces the current calendar data in the destination app.
  • If you use another browser or device, local hide/show choices do not follow automatically.
Helpful Tips
  • Keep event titles short so they fit better in printed cells.
  • Use audience colors consistently so readers can scan quickly.
  • Use PDF or image export when you want recipients to see the exact visual layout.
  • Use ICS when you want recipients to import the visible month's events into another calendar app.
  • If you want the Jamaat feed visible in exports, leave USA Jamaat on before exporting.
