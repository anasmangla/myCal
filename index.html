      How To Use myCal

      A quick guide for planning, styling, sharing, and editing notes inside the calendar.

      Calendar Basics
      • Use the month selector at the top to switch months.
      • Use the `Islamic dates` and `U.S. holidays` toggles to show or hide those labels.
      • Click the month title to rename the calendar for that month.
      • Use `Settings` to change colors, fonts, title sizing, and audience colors.
      Adding Events
      • Double-click a regular in-month date cell to add an event quickly.
      • Click an event chip to edit it.
      • Leave `Start time` blank if the event should be treated as all-day.
      • Use the weekday checkboxes in the event form to repeat an event weekly.
      Right-Click Actions
      • Right-click a date cell to change its background color or hide holiday / Islamic labels for that day.
      • Right-click an event chip to modify, move, or remove that event.
      • Right-click a non-date box image to remove just that image.
      • Right-click a non-date box itself to add or clear images for that box.
      Non-Date Boxes
      • Double-click a non-date box to type directly inside the box.
      • Use the inline controls to change font family, font size, bold, and italic.
      • Text wraps automatically and stays inside the box with scroll support for longer notes.
      • Click outside the editor or press `Esc` to stop editing.
      Images In Non-Date Boxes
      • Drag an image file into a non-date box to add it.
      • Drag an existing thumbnail from one non-date box to another to move it.
      • Drag a thumbnail to the trash bar at the bottom of the screen to remove it.
      • You can also use the side panel image picker when a non-date box is selected.
      Export And Sharing
      • `Print / Save PDF` creates a printable month view.
      • `Export image` saves the visible calendar as an image.
      • `Export ICS` downloads the events that appear in the current month.
      • `Export JSON` and `Import JSON` let you back up or restore the month data.
      Saved Data
      • Your static calendar changes are saved locally in the browser.
      • `Reset saved data` clears the saved local month data for the static app.
      • If you import JSON, the imported month replaces the current loaded document.
      Best Practices
      • Keep event titles short so they fit better in printed cells.
      • Use audience colors consistently so readers can scan quickly.
      • Use non-date boxes for overflow notes, reminders, contacts, or announcements.
      • Export a PDF or image before sharing if you want recipients to see exactly what you see.
